# Methods

## Baseline Methods

We implement the following baseline methods from RoboTwin:

### 1. ACT (Action Chunking Transformer)
- Efficient action prediction
- Temporal consistency
- Project url: [https://github.com/tonyzhaozh/act](https://github.com/tonyzhaozh/act)
- Paper url: [https://arxiv.org/pdf/2304.13705](https://arxiv.org/pdf/2304.13705)

### 2. DP (Diffusion Policy)
- Multimodal action distribution
- Robust to noise
- Project url: [https://github.com/real-stanford/diffusion_policy](https://github.com/real-stanford/diffusion_policy)
- Paper url: [https://arxiv.org/pdf/2303.04137](https://arxiv.org/pdf/2303.04137)

### 3. DP3 (3D Diffusion Policy)
- Multimodal action distribution
- Robust to noise
- Project url: [https://github.com/YanjieZe/3D-Diffusion-Policy](https://github.com/YanjieZe/3D-Diffusion-Policy)
- Paper url: [https://arxiv.org/pdf/2403.03954](https://arxiv.org/pdf/2403.03954)

### 4. RDT (Robot Diffusion Transformer)
- Scalable architecture
- Strong performance
- Project url: [https://github.com/thu-ml/RoboticsDiffusionTransformer](https://github.com/thu-ml/RoboticsDiffusionTransformer)
- Paper url: [https://arxiv.org/pdf/2410.07864](https://arxiv.org/pdf/2410.07864)

### 6. Pi0
- Project url: [https://github.com/Physical-Intelligence/openpi](https://github.com/Physical-Intelligence/openpi)
- Paper url: [https://www.pi.website/blog/pi0](https://www.pi.website/blog/pi0)

### 7. Pi0.5
- Project url: [https://github.com/Physical-Intelligence/openpi](https://github.com/Physical-Intelligence/openpi)
- Paper url: [https://www.pi.website/blog/pi05](https://www.pi.website/blog/pi05)

### 8. DexVLA (Vision-Language Model with Plug-In Diffusion Expert for Visuomotor Policy Learning)
- Project url: [https://github.com/juruobenruo/DexVLA](https://github.com/juruobenruo/DexVLA)
- Paper url: [https://arxiv.org/pdf/2502.05855](https://arxiv.org/pdf/2502.05855)

### 9. Tiny-VLA (Towards Fast, Data-Efficient Vision-Language-Action Models for Robotic Manipulation)
- Project url: [https://tiny-vla.github.io/](https://tiny-vla.github.io/)
- Paper url: [https://events.infovaya.com/uploads/documents/pdfviewer/a2/99/204821-0245.pdf](https://events.infovaya.com/uploads/documents/pdfviewer/a2/99/204821-0245.pdf)

### 10. Openvla-oft
- Project url: [https://github.com/moojink/openvla-oft](https://github.com/moojink/openvla-oft)
- Paper url: [https://arxiv.org/pdf/2502.19645](https://arxiv.org/pdf/2502.19645)
